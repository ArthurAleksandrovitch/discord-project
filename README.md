# Discord Project — главная страница

Это первый вариант сайта, созданный с нуля по предоставленному референсу.

## Запуск

Вариант 1 — просто открыть `index.html` в браузере.

Вариант 2 — через VS Code Live Server:
1. Открыть папку проекта.
2. Открыть `index.html`.
3. Нажать `Go Live`.

## Структура

- `index.html` — разметка сайта
- `styles.css` — дизайн и адаптивность
- `script.js` — небольшая интерактивность
- `assets/hero-reference.png` — иллюстрация из предоставленного референса

## Следующий этап

После проверки внешнего вида можно:
- заменить временные тексты на данные проекта;
- подключить настоящий Discord/server backend;
- сделать авторизацию;
- добавить страницы входа и регистрации;
- сделать отдельную страницу самого Discord-интерфейса.
